04 / FROM IMAGE TO EXPLANATION

How it works

Every screening follows the same validated software workflow.

  1. 01Acquire

    Upload a supported medical image and select a patient record.

  2. 02Validate

    Check format, image quality, exposure, and exact duplicates.

  3. 03Route

    Identify the modality and select the matching specialist.

  4. 04Screen

    Apply the trained model, threshold, and uncertainty band.

  5. 05Interpret

    Review model attention, next steps, and a local report.

Specialist models

Separate EfficientNet-B0 models assess chest X-rays, retinal fundus photographs, and oral histopathology. Scores are model outputs, not calibrated disease probabilities.

Explainable output

Grad-CAM uses a verified matching checkpoint. It helps inspect model attention without claiming that highlighted regions are lesions.

Clinical context

Questionnaire recommendations remain separate from image predictions. The clinical workspace includes patient history, bilingual reports, and local analytics.

Experimental screening aid. No prospective clinical validation. Inconclusive and rejected inputs remain visible rather than being forced into a positive or negative result.

05 / MEASURE, THEN INTERPRET

Evidence over assumptions.

Review the model score, decision threshold, and uncertainty together. A model score is not a probability of disease.

Run a screening to enable CSV export.

SCORE & DECISION THRESHOLD

Model score ≠ diagnostic certainty

The threshold is the cutoff for raising a screening flag. A score above it is flagged; a score below it gets no flag. For example, a 40% score exceeds a 25% threshold. These percentages are model outputs, not the chance of disease. Scores within the uncertainty band return INCONCLUSIVE.

Clinical accuracy requires independent validation. A no-flag result does not rule out disease. Review all results with a qualified healthcare professional.

06 / ABOUT THE PROJECT

Built for local care.
Grounded in evidence.

Mediscan AI is an experimental screening aid for tuberculosis, diabetic retinopathy, and oral cancer. It supports clinical review without replacing it.

Use installed local models or configured private remote specialists. Image validation, modality routing, and uncertainty handling connect to local patient records and automatic PDF reports. Model attention is available when the selected provider supports it.
